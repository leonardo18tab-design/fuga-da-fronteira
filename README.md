# Fuga da Fronteira

Jogo arcade satírico em HTML5/JavaScript, empacotado para Android em uma WebView local.

## Jogar
Abra [index.html](index.html) no navegador. No celular, use o aparelho em paisagem e os controles na tela.

## Gerar APK
A compilação é automatizada pelo GitHub Actions. Abra a aba **Actions**, escolha **Build Android APK** e baixe o artefato **Fuga-da-Fronteira-APK** quando a execução terminar. O APK debug é destinado a testes e instalação direta em Android (API 23+).
